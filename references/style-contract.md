# 样式契约（业务报表·模板样式保真）

> 来源：QPWY 导出模板 `03-卖断货-重点关注商品_优化预览_10-10.xlsx`（客户提供，勿覆盖）+ 经验块 `excel-template-style-fidelity.md`。
> **硬规则：任何业务报表 XLSX 生成必须完整套用本契约，禁止从零自拟配色；交付前必须 openpyxl 回读 + 渲染双验证。**

## 字体

- 全表：**Microsoft YaHei（微软雅黑）**
- 标题：16 号加粗 #111827
- 副标题：10 号 #6B7280
- 表头：11 号加粗，深底 #1F2937 白字居中
- 明细：10-11 号

## 色板（等级四色）

| 等级 | 深底（优先级列/看板） | 浅底（等级列） | 深字 |
|---|---|---|---|
| A 红 | DC2626 | FEE2E2 | B91C1C |
| B 橙 | C2410C | FFEDD5 | C2410C |
| C 黄 | A16207 | FEF9C3 | A16207 |
| D 灰 | 4B5563 | F3F4F6 | 4B5563 |

- **优先级列** = 等级深色底 + 白字（今日必盯/持续缺货/频发缺货/低销频缺）
- **等级列** = 浅色底 + 同色调深字

## 布局（卖断货报表·默认结构）

1. **一眼看懂** sheet：4 色块看板（22 号加粗 / 11 等级名 / 10 灰描述，行高 40）+ 「怎么用」5 条（A:F 合并）+ 供商 TOP(A+B) 榜（表头深色 17 行、数据 18 行起）
2. **今日必盯 / 全量名单** sheet：10 列明细 + 表头深色 + auto_filter

## 明细 10 列结构

| 列 | 内容 | 列宽 |
|---|---|---|
| A | 优先级 | 12 |
| B | 等级 | 6 |
| C | 商城商品码 | 12 |
| D | 商品名称 | 36 |
| E | 供商 | 28 |
| F | 大分类（流通品/非流通品=flow+"品"） | 10 |
| G | 连续缺货天 | 12 |
| H | 近30天售罄天 | 14 |
| I | 建议动作 | 26 |
| J | 入选说明 | 28 |

- auto_filter：`A4:J(4+len)`

## 验证入口（交付前必跑）

1. **openpyxl 回读断言**：色块/表头深底/优先级列深色/等级列浅色/筛选范围/列宽
2. **JSON 一致性**：XLSX 数据行数 = JSON rows 条数；A/B/C/D 分布一致
3. **渲染检查**（可选）：xlsx→PDF（LibreOffice）肉眼核对版式

## 子集/筛选报表（如"只看 A 类"）

- 以已交付的模板样式报表为源，**整行复制值+样式**（copy cell style）生成子集报表，保持契约
- 匹配键用字符串归一化（JSON int item_id ↔ Excel str），避免类型不匹配静默 0 命中
