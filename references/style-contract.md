# 样式契约（业务报表·模板样式保真）

> 来源：QPWY 导出模板 `03-卖断货-重点关注商品_优化预览_10-10.xlsx`（客户提供，勿覆盖）+ 经验块 `excel-template-style-fidelity.md`。
> **硬规则：任何业务报表 XLSX 生成必须完整套用本契约，禁止从零自拟配色；交付前必须 openpyxl 回读 + 渲染双验证。**

## 适用范围（最高优先级硬规则）

- **固定报表（①卖断货 ②爆卖 ③热度 ④供货缺货）**共用下面的字体和色板，禁止自拟配色。
  页、列、标题锁在**该报表自己的基线**上，不能串页：
  - ① 卖断货：本文件「布局」「明细 10 列」，脚本 `scripts/report_soldout.py`
  - ④ 供货缺货：本文件「④ 供货缺货」，脚本 `scripts/report_supply_short.py`。不要改回卖断货那 10 列
  - ② 爆卖：本文件「② 爆卖（三 sheet）」，出表器 `scripts/render_hot_sale.py`
  - ③ 热品预判缺货：未开通，不要提前出表
  - 与该报表基线不一致 = 缺陷，必须回归修复
  - **禁止 AI 现场自写生成器**（自写必然导致数据口径或样式漂移）
- **自定义输入（第 5 个入口，非固定报表）**：样式可自定义，按老板要求灵活设计，**不受本契约约束**；
  但数据正确性仍须回读校验（条数、金额、口径与来源一致）。
- 判断标准：**只要是固定 4 报表之一 → 锁定模板；只要走自定义输入 → 可灵活。**

## 验证入口（交付前必跑）

1. **openpyxl 回读断言**：色块/表头深底/优先级列深色/等级列浅色/筛选范围/列宽

3. **渲染检查**（可选）：xlsx→PDF（LibreOffice）肉眼核对版式

## ② 爆卖（三 sheet，自己的基线，色板仍用上面那套）

**唯一出表入口：`scripts/render_hot_sale.py`（读 JSON 出 XLSX）。禁止现场自写生成器、禁止另起配色。**

一个 Excel、三个 sheet，**顺序固定为 `规则总览` → `规模爆品` → `速度爆品`**（总览放第一页：老板打开先看规则，翻一页就是数据）。
- 两个明细页**只放数据**：r1 标题、r2 副标、r3 表头、r4 起数据，不塞规则块。
- 两榜的入选条件、四档看板、指标定义、备注判定**集中到 `规则总览` 一页**。

### 入榜判据（样式之外，但必须与表内档位一致）

- 规模：近 7 日 ≥50 件 且 加速比 ≥1.5 且 上涨 ≥3 天
- 速度：近 7 日 ≥10 件（**不设规模上限**）且 近 3 日均 ≥5 且 加速 ≥3 且 上涨 ≥3 且 单日峰值 ≤5×其余 6 日均值（且峰值 ≥10）且 后 3 日无 0 断点 且 非供给恢复型
- 新品：前 4 日 =0 且 前两个可验证快照日有货未断 且 近 3 日均 ≥5 且 后 3 日连续有量 且 末日 ≥ max(第5日, 第6日)×0.6
- 同一商品**允许同时出现在两个 sheet**（规模大的陡品不应被速度榜漏掉）

### 交付前验证入口

1. sheet 名与顺序必须是 `规则总览` → `规模爆品` → `速度爆品`，三页且只有这三页
2. 明细页 r1/r2/r3 字体与色号逐格断言（16B#111827 / 10#6B7280 / 11B 白字#1F2937）
3. 总览页 r6 / r13 四块浅底按序位对上（FEE2E2 / FFEDD5 / FEF9C3 / F3F4F6）
4. **总览页规则文字都在且非空**：r5 规模条件、r12 速度条件、r19~r22 四条通用口径（规则缺失 = 缺陷，不是可选项）
5. 备注列（第 12 列）每条异常都写了原因，不允许只写「异常」两字
6. `auto_filter = A3:L{末行}`、`freeze = A4`
7. 数据行数 = JSON `size` / `speed`+`new`；档位分布 = JSON `meta.counts`
8. 档位列浅底+深字，其余列白底（无斑马纹）

### 禁止

- 不加图表、不加斑马纹
- **不得省略 `规则总览` 页**（入榜条件、四档门槛、指标定义缺一不可）
- 明细页**不得回填任何规则文案**（会重新吃掉一屏，拆页的唯一目的就是腾出这一屏）
- 不用 S/A/B/C 字母分档；档位名固定为 爆款/旺销/畅销/起量、黑马/猛涨/起势/新品
- 不新造颜色、不改行位、不改列序

## 子集/筛选报表（如"只看 A 类"）

- 以已交付的模板样式报表为源，**整行复制值+样式**（copy cell style）生成子集报表，保持契约
- 匹配键用字符串归一化（JSON int item_id ↔ Excel str），避免类型不匹配静默 0 命中
