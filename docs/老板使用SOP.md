# 老板用：三步装好，每天一句话出报表

> 全程不涉及 GitHub、不涉及数据库、不需要您修改任何文件。
> 全部操作只有三件事：**打开 → 复制一段话 → 拖一个文件**。

---

# 第 1 步：打开

1. 豆包点**新对话**
2. 顶部切到 **「工作」** 模式（请选「工作」，不要选「对话」）
3. 执行环境选 **「云电脑」**

> 这三项请先确认好，否则后续步骤无法进行。

---

# 第 2 步：把下面这一段复制发给豆包

```
帮我安装「QPWY 电商报表」技能，来源：https://github.com/Leozhangshouhai/doubao-ecommerce-data-bot
分支选 saas-tencent，装在云电脑环境，装好后告诉我。
```

**直接复制粘贴即可，无需改动任何字。**

豆包会自行下载安装。完成后会回复"装好了"。

随后请再发送一句，确认安装成功：

```
你是 QPWY 机器人吗
```

**回复"是"即安装成功。** 若回复其他内容，说明未安装成功，请联系技术处理。

---

# 第 3 步：传一个文件

技术会把一个文件发给您，文件名为 **`ecommerce_bot.yaml`**。

1. 将该文件**拖入对话框**（或点击附件上传）
2. 发送一句话：

```
这是我的配置文件，帮我初始化
```

3. 豆包会回复"配置好了"，并询问：

> **是否每天早上自动出报表？几点？**

4. 回复一个时间即可：

```
每天早上 8:30
```

（时间由您决定；如不需要自动推送，回复"不用定时"即可。）

**至此安装完成。**

> ⚠️ 该文件内含数据库密码，**请勿转发他人，也请勿上传至群聊或网盘**。
> 文件内容已由技术方确认无误，无需您打开或修改。

---

# 装好之后，每天怎么用

**每天早上会自动收到四张表**（前提是第 3 步已设定时间）。

如需临时获取，发送对应的一句话即可：

| 需求 | 发送 |
|---|---|
| 全部报表 | **出报表** |
| 只看卖断货的 | **出卖断货报表** |
| 只看爆卖的 | **出爆卖报表** |
| 只看快断货的 | **出热品预判缺货报表** |
| 只看哪些供商缺货 | **出供货商快缺货** |
| 其他问题 | 用自己的话直接提问，例如"昨天有哪些 A 类断了" |

**四张表一次全部产出，无需逐张确认。**

---

# 如遇到问题

**处理方式只有一个：截图发给技术。请勿自行修改文件或重新安装。**

| 您看到的现象 | 可能原因 | 建议处理 |
|---|---|---|
| 安装后豆包不识别 | 模式或环境选择有误 | 返回第 1 步核对三项 |
| 提示"校验不通过" | 配置文件存在问题 | 截图发技术，修正后重新发送 |
| 提示"连接失败" | 密码或网络问题 | 截图发技术 |
| 报表日期显示为昨天 | **属正常现象** | 无需处理，次日照常出表 |
| 某个商品数据看着异常 | 数据本身即如此 | 无需处理 |

---

# 记住三点即可

1. **进入「工作」模式，使用「云电脑」** —— 三项都要符合
2. **配置文件只需拖入，不打开、不转发**
3. **遇到问题截图发技术，无需您做任何改动**
