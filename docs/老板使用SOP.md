# 老板使用 SOP v1.2 —— 电商数据机器人 QPWY机器人（doubao-ecommerce-data-bot）

> 适用对象：老板/非技术人员。全程不需要写代码、不需要碰 SQL。
> 一句话：**安装一次技能 + 上传一次配置文件，之后每天开口说"出报表"就行。**

---

## 0. 第一步：安装机器人技能（一次性，约 5 分钟）

> 机器人的"脑子"（技能）通过 GitHub 分发。安装一次，之后换电脑/换账号只需重新安装一次。

**操作步骤：**
1. 打开豆包，**进入「工作」模式**（豆包界面顶部选「工作」，不要选「对话」——对话模式不加载机器人技能）
2. 找到**安装技能**的入口（工作台 → 技能 / 添加技能）
3. 输入技能来源的 GitHub 仓库地址：
   ```
   https://github.com/Leozhangshouhai/doubao-ecommerce-data-bot
   ```
4. 如果安装时有分支选择：**必须选 `saas-tencent` 分支**
   （⚠️ 仓库默认分支尚未切换，切换前务必手动选 saas-tencent；切换完成后可直接用默认）
5. 安装完成 → 确认执行环境为**云主机（云端服务器）**，不是本地电脑
6. **验证安装成功**：对机器人说 **"你是 QPWY 机器人吗"** → 应回答"是 QPWY 机器人（配置驱动的电商数据机器人）"

**没反应？** 先看第 6 节报错对照表（"安装后机器人没反应"条目）。

---

## 1. 第二步：准备连接资料（一次性，找技术要，约 10 分钟）

| 需要 | 说明 | 从哪来 |
|---|---|---|
| 配置文件 `ecommerce_bot.yaml` | 唯一的配置文件，模板我们发给你 | 问 AI 要，或从 GitHub 仓库下载模板 |
| 6 项"连接资料" | 你的数据库信息 | **找你的技术接口人（运维/开发）要**，见下表 |

**⚠️ 环境要求（必须先确认）：**
1. 豆包进入 **「工作」模式**（不是「对话」——对话模式不加载机器人技能）
2. 执行环境为**云主机（云端服务器）**，不是本地电脑——所有校验、连库、出报表都在云端完成，与交付方一致；本地电脑会因系统权限拦下载入配置和运行
3. 若误入本地电脑环境，直接对 AI 说：**"请切换到云主机（云端服务器）环境执行，不要用本地电脑环境"**

**找技术要资料，直接把这句发给他：**
> "请给我：数据库是走**跳板机**还是**直连**；如果跳板机，给我地址/账号/密码；**两个实例**（订单库、商品库）的内网地址和端口；一个**只读**账号和密码。"

> ⚠️ 强调"只读"：只读账号只能查数据、不能改数据，你的库存/订单数据是安全的。

---

## 2. 第三步：填写配置文件（10 分钟）

1. 拿到文件 `ecommerce_bot.yaml`
2. 用**记事本 / VS Code / 文本编辑器**打开（不要用 Word）
3. **只改下表标 ⭐ 的项目**，其他一律不要动：

| 配置文件位置 | 填什么 | 怎么拿 |
|---|---|---|
| ⭐ `customer` | 你的公司/客户名 | 自己定，如"全品无忧" |
| ⭐ `conn.mode` | `jump` 或 `direct` | 问技术：走跳板机填 `jump`，直连填 `direct` |
| ⭐ `conn.jump_host` | 跳板机地址 | 技术提供（仅 jump 模式） |
| ⭐ `conn.jump_user` | 跳板机账号 | 技术提供（仅 jump 模式） |
| ⭐ `conn.jump_password` | 跳板机密码 | 技术提供（仅 jump 模式） |
| ⭐ `conn.targets.order` | 订单库内网地址+端口 | 技术提供（如 `{ host: 10.x.x.x, port: 3306 }`） |
| ⭐ `conn.targets.goods` | 商品库内网地址+端口 | 技术提供 |
| ⭐ `db.user` | 数据库只读账号 | 技术提供 |
| ⭐ `db.password` | 数据库只读密码 | 技术提供 |
| （其余：tunnel / caliber / tables / reports / style） | 默认已配好 | **不要改** |

4. 保存文件。**文件名必须保持 `ecommerce_bot.yaml`**——不要改成"配置"、"新建文档"等任何名字。

---

## 3. 第四步：把配置文件交给 AI（2 分钟）

1. 打开豆包，**进入「工作」模式**；确认执行环境为**云主机**
2. 把 `ecommerce_bot.yaml` 文件**直接拖进对话框**（或点上传附件）
   - ⚠️ **如果 AI 弹出了报表选择菜单/选择框**：不要被它挡住，直接拖文件上传即可（菜单在文件未就绪前不应出现；出现也不影响上传）
   - 也可以直接说：**"上传 ecommerce_bot.yaml 配置文件"**，同时把文件拖进去
3. 说一句话：
   > "这是我的配置文件，帮我校验一下能不能用"
4. AI 会回复两种情况：
   - ✅ **校验通过** → 会接着问你："**是否需要每天自动推送卖断货报表？几点？**"
     - 想自动推送 → 回答："每天早上 9 点"（时间自己定）
     - 不想定时 → 回答："不要定时，我自己说"
   - ❌ **提示哪一项没填/填错** → 打开文件按提示补上，重新上传

---

## 4. 第五步：每天怎么用（30 秒）

> ⚠️ **每天使用前确认：豆包处于「工作」模式 + 云主机环境**（对话模式机器人不响应；本地电脑会被权限拦）。

| 你想干嘛 | 就这么说 |
|---|---|
| 出今天的卖断货报表 | "出卖断货报表" 或 "出今天的卖断货报表" |
| 只看某一类 | "卖断货只看 A 类" |
| 按供商排前几名 | "按供商排前 5" |
| 哪些持续缺货 | "哪些是持续缺货的" |
| 其他想法 | 直接说人话问 AI（只读分析） |

**现在能用的报表菜单：**
| 报表 | 状态 |
|---|---|
| ① 卖断货（哪些商品卖断货了） | ✅ 已开通 |
| ② 爆卖 / ③ 热度 / ④ 供货缺货 | 建设中（先不用） |
| 自定义问题 | ✅ 可直接问 |

**定时推送（可选）：**
- 首次校验通过时已设定时 → 每天到点**自动收到**报表，不用自己说
- 没设定时/想改时间 → 直接说："帮我设定时推送，每天早上 X 点" 或 "把定时改成 X 点 / 取消定时"

**时间说明（重要）：**
- 库存每天 **23:50** 自动同步
- 你上午看的报表 = **前一天的数据**（正常现象，不用怀疑）

---

## 5. 安全须知（必读）

1. 配置文件里有数据库密码：**只存在你电脑/私密会话里**，不要转发给别人、不要传到 GitHub/网盘/微信群
2. 出问题先看下面的报错对照表，再找技术接口人
3. 换电脑 / 换账号 / 换手机：把配置文件**重新上传一次**即可，不用重新配置

---

## 6. 报错对照表（老板版）

| 你看到/遇到 | 原因 | 怎么办 |
|---|---|---|
| 安装后机器人没反应（答非所问） | ① 在「对话」模式（不加载技能）② 安装时分支选错/没装成功 | ① 切到「工作」模式 ② 重新安装技能，分支选 `saas-tencent`，装完问"你是 QPWY 机器人吗"验证 |
| "文件名必须是 ecommerce_bot.yaml" | 文件名被改了 | 改回这个名字再传 |
| "db.password 还是占位符" | 密码没填 | 打开文件，把 `<只读密码>` 换成真实密码 |
| "xxx 必填" | 某项没填 | 按提示补上（资料找技术要） |
| "连接失败 / 不可达" | 跳板机/地址/端口不对，或网络不通 | 核对资料，找技术确认 |
| 启动器/文件权限错误，说要切环境 | 会话跑在**本地电脑**环境 | 对 AI 说："请切换到**云主机（云端）环境**执行" |
| 弹出了报表选择框但我想上传文件 | 配置未就绪前不应弹菜单 | 忽略菜单，直接拖入 yaml 文件上传 |
| 报表日期是昨天 | 正常 | 库存每天 23:50 同步，上午看=昨天 |
| "表不存在 / 查询失败" | 表名与你的库不一致 | 找技术要正确表名，让 AI 帮你改 |

## 7. 交付物长什么样

- **Excel 报表**：带彩色等级（A 红 / B 橙 / C 黄 / D 灰）、一眼看懂看板、TOP 供商榜、可筛选明细
- **AI 一句话解读**：今天卖断货 X 个、A 类重点关注 Y 个、TOP 供商是谁
